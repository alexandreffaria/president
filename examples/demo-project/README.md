# Trailhead (demo project)

A pretend offline-first hiking trip planner (a web app that works without signal on the trail).
It exists so you can try president.

- `decisions/` holds the decision cards an agent wrote for this project.
- `docs/decisions.md` is where an agent records decisions after the human resolves them.

To see the cards in your hub, let president copy it and register the copy (clicking around in
the UI changes the card files, so don't register this folder itself):

```sh
president demo
```
